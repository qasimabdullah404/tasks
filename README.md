# 📝 Tasks

A minimalist yet mighty Task API that does one thing and does it well—manages your tasks so you can focus on more important things, like deciding what to have for lunch.

## 🚀 Features

- **RESTful API**: Because SOAP belongs in the bathroom.
- **Dockerized**: Spin it up faster than you can say "containerization."
- **Swagger Documentation**: API docs so clear, even your non-tech-savvy friend can understand.
- **Custom Logging**: Logs your tasks' life stories with the flair of a seasoned novelist.

---

## 📦 Tech Stack

- **Node.js** – The event-driven, non-blocking I/O champion.
- **Express** – Fast, unopinionated, minimalist web framework.
- **Docker** – Because shipping code should be as easy as shipping containers.
- **Swagger** – For when your API needs a modeling career.

---

## 🛠️ Running

   ```bash
   git clone https://github.com/qasimabdullah404/tasks.git
   docker compose up -d
   ```
